## The entry

> 🏝️

One emoji, nothing else: the desert island — palm tree, sand, sea and escape in a single glyph. It is the trip everyone pictures when they say "dream vacation".

## How it works

`main.ts` deterministically writes exactly that emoji to `/output/entry.txt` — no randomness, no network, no input.

Run it with Node.js:

```sh
node main.ts
```
